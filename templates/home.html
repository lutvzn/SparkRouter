About these numbers

Totals cover finished requests within the configured retained history window (at most 10,000 records) across API and test chat. Clearing History clears these totals too. Provider requests count each provider once per request; usage is assigned to the selected provider only. Cached tokens are cache reads, not cache writes, and are already included in input. Prompt cache by combo counts a cache hit when a request reported at least one cached token; requests whose provider did not report cache usage are left out of the rate, and the combo's current cache-awareness setting is shown, not the one each request used. Spend includes known provider-reported USD, not necessarily your full invoice. Missing usage or spend is shown as an em dash, not zero. Older records without a provider snapshot appear under their connection name.
