Export

Downloads custom providers, named connections, and combos with their ordered steps. API keys, gateway keys, cached model lists, history, and timestamps are never included. This is not a full backup; endpoints and names can still be sensitive.

Import

Paste a configuration document exported from another gateway. The format has no fields for API keys or other secrets; do not add any. Preview shows what would be created: importing never overwrites or merges existing entries, a conflicting combo name aborts the whole import, and every imported connection starts disabled with no API key.

Per import: at most 2 MiB of JSON, 100 explicit groups, 500 connections, 200 combos, 50 steps per combo, and 2,000 total steps. The encoded form must also fit the 4 MiB request limit.
